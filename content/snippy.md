The terminal client for a running [Snipo server](../snipo/), available for macOS, Linux and Windows. It ships in the same release as the server and is also available through Homebrew.

- Browse and search snippets with keyboard navigation
- Create and edit snippets, including opening content in your preferred editor
- Move between files in a snippet and copy their contents to the clipboard
- Toggle favorites and manage snippets without leaving the terminal

After installing, run `snippy config` to enter your Snipo server URL and a dedicated API token with write permission, then launch `snippy`.
