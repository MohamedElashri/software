A snippet manager you run yourself, built for a single user: one master password protects the whole instance and there are no accounts to manage. The web app holds your code fragments, commands and notes, and separate clients let you reach them from the terminal, VS Code and the browser.

- Snippets with multiple named files, folders, tags, favorites, archiving, expiration and edit history
- Search and filter by text, tag, folder, language or favorite
- A choice of Ace, CodeMirror 6 or Monaco editors, plus Markdown preview and right-to-left text
- Public share links, API tokens, encrypted backups and optional sync with GitHub Gists
- Snippy, a terminal UI for browsing, editing and copying snippets
- A VS Code extension to search, insert and save snippets, and a Chrome and Firefox extension that saves selected text
