A desktop app for reviewing code changes, whether they sit in a local Git repository, a GitHub pull request or a GitLab merge request. Open a repository or paste a PR or MR URL, then read the diff, leave feedback and move through the code in one window.

- Local changes, GitHub pull requests and GitLab merge requests, including private GitHub repositories with a token
- Split or unified diffs
- Threaded feedback on changes
- Code navigation through a language server, turned on per review after you trust the repository
- Customizable themes and fonts
- Keyboard shortcuts for reviewing, listed with `?`
